# ADR-0007: SLO とエラーバジェットでリリースを制御する

- 状態: 採用（2026-09-22）

## 決定

- SLO は `tools.json` にツールごとに書く（既定: 可用性 99.5% / 28 日）。
- SLI は GraphQL Analytics の `workersInvocationsAdaptive`（`status != success` を失敗）と、synthetic 監視の結果。
- `ops.yml`（cron）:
  - 30 分ごと: 本番 smoke（synthetic）。失敗が 2 回続いたら Issue（`incident` ラベル）を起票
  - 日次: SLO・エラーバジェット・無料枠の消費を集計して Issue のダッシュボードを更新。バジェット枯渇で `release-freeze` を立てる
- `release-freeze` が立っている間、Release PR の checks は `fix:` / `revert:` 以外を含むと失敗する。
- 障害対応の手順は `docs/runbooks/`（ロールバック、無料枠枯渇時の縮退、secret 漏洩時の失効）。
