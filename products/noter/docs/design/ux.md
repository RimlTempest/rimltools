# UX 設計

## 1. 誰のために・何を

| ペルソナ                        | やりたいこと（JTBD）                                                 | 決定的な要件                                                     |
| ------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **書き手**（設計者・PM）        | 設計メモ・手順書を Markdown + Mermaid で書き、チームと同時に直したい | 入力遅延なし、図が即座に更新、リンク 1 本で共有                  |
| **設定の管理者**（SRE・開発者） | YAML / TOML / JSON の設定を、隣の人と画面共有せずに一緒に直したい    | 構文エラーが**その場で**分かる、整形、コピー・ダウンロードが速い |
| **閲覧者**（レビュー担当）      | 送られたリンクを開いて読む。編集はしない、ログインもしたくない       | ログイン不要、読み込み 1 秒、印刷できる                          |
| **支援技術ユーザー**            | スクリーンリーダー / キーボードのみで上記すべて                      | WCAG 2.2 AAA（`accessibility.md`）                               |

やらないこと（v1）: フォルダ階層、コメント機能、変更履歴 UI、WYSIWYG、画像アップロード
（R2 を使わないため。画像は外部 URL）。

## 2. 原則

1. **開いた瞬間に書ける。** ログイン・設定・チュートリアルを挟まない。初回はゲスト。
2. **同期を意識させない。** 「保存」ボタンは無い。状態は 1 つのピルで示し、異常時だけ言葉で説明する。
3. **壊れない。** オフラインでも入力できる、上限に達しても入力できる、ダウンロードは常にできる。
4. **文書種別で UI を変えない。** ツールバーの並びは 4 種別で同じ。違いはプレビューと診断だけ。
5. **他人の存在は静かに。** カーソルと名前は見えるが、通知は入退室の 1 回だけ。

## 3. 情報設計

```
/                      ホーム
├─ 未ログイン: 「noter」説明 + [Markdown で始める][YAML][TOML][JSON] + [Google でログイン]
└─ ログイン済/ゲスト: 最近の文書（table）+ [新規作成 ▾] + アカウント
/d/:id                 エディタ（本体）
/s/:token              共有リンク入口（表示なし → 即 /d/:id へ。失効時のみ画面）
/sign-in               ログイン
/settings/account      アカウント（Google 連携、表示名。アカウント削除は v1 では置かない）
```

ナビゲーションは `AppShell` のヘッダに **ホーム / 新規作成 / アカウント** の 3 つだけ。

## 4. 画面

### 4.1 ホーム（`/`）

- ゲスト・ログイン済とも同じレイアウト。上に **新規作成**（種別 4 つの大ボタン、`44px` 以上）。
- 最近の文書: `<table>`（見出し: タイトル / 種別 / 権限 / 最終更新 / 操作）。
  最終更新は相対時刻 + `title` ではなく `<time datetime>` + 可視の絶対時刻（ホバー不要）。
- 行操作: 開く（行全体ではなくタイトルのリンク）、… メニュー（名前変更 / 共有 / 削除）。
- 空状態: 「まだ文書がありません」+ 新規作成ボタンへの誘導文。
- ゲスト向け注意（ログイン済では非表示）: 「この端末のブラウザに紐づいています。
  別の端末でも使うには Google でログイン」。消せる（`localStorage`）。

### 4.2 エディタ（`/d/:id`）

````
┌ AppShell header ─────────────────────────────────────────────────────────────┐
│ noter   [タイトル(編集可)]  [Markdown]      ●接続済 · 保存 12:34   👤👤+2  [共有] [⋯] │
├ ツールバー ───────────────────────────────────────────────────────────────────┤
│ [エディタ][分割][プレビュー]   [整形] [問題 2]   [取り込み ▾][書き出し ▾]        │
├──────────────────────────────────┬────────────────────────────────────────────┤
│ CodeMirror                       │ プレビュー                                 │
│  1  # 設計                       │  設計                                      │
│  2                               │                                            │
│  3  ```mermaid                   │  [図: flowchart]  (ソースを表示)           │
│                                  │                                            │
├──────────────────────────────────┴────────────────────────────────────────────┤
│ 問題 (2): ▸ 3 行目 5 列: 予期しないトークン  ▸ mermaid #1: Parse error         │
└───────────────────────────────────────────────────────────────────────────────┘
````

- **タイトル**は `<input>`（`aria-label="文書のタイトル"`）。blur / Enter で保存（server function）。
  editor 権限以上。viewer には `<h1>` として表示。
- **種別バッジ**は変更不可の `<span>`（変更は「書き出し → 別種別で新規」で行う）。
- **状態ピル**: `ConnectionState` × 保存状態を 1 つの文言に畳む（§5）。
- **参加者**: アバター（イニシャル + 色）最大 3 + 「+N」。クリックで `<ul aria-label="参加者">`
  のポップオーバー（名前・権限）。自分は含めない。
- **共有**: `<dialog>`。owner のみ。§4.4。
- **⋯ メニュー**: 名前変更（= タイトルにフォーカス）/ 複製 / 削除（owner）/ 退出（member）/
  印刷 / ショートカット一覧。
- **表示切替**: 3 つの `<button aria-pressed>`。既定は幅 ≥ 48rem で「分割」、未満で「エディタ」。
  `localStorage` に記憶。
- **整形**: yaml / toml / json は整形（失敗時は「問題」に理由）。markdown は非表示。
- **問題**: 件数付き `<button aria-expanded>` で下部パネルを開閉。各項目はその位置へ
  ジャンプする `<button>`。0 件のときは「問題なし」で無効化しない（押すと「問題はありません」）。
- **取り込み**: ファイル選択 / ドラッグ&ドロップ / 貼り付け（クリップボード）。
  「置き換える」か「カーソル位置に挿入」を確認する `<dialog>`。
  `MAX_DOCUMENT_BYTES` 超は拒否して理由を出す。
- **書き出し**: ダウンロード（`.md` / `.yaml` / `.toml` / `.json`）/ クリップボードにコピー /
  **変換して新規作成**（yaml ⇄ json ⇄ toml。変換不能なとき理由）/ raw URL をコピー。
- **プレビュー**（markdown）: DOMPurify 通過後の HTML。Mermaid ブロックは遅延読み込みで
  SVG。エラー時はブロックの位置に赤枠 + メッセージ、ソースを表示。
  見出しに id を振り、目次は付けない（v1）。
- **プレビュー**（yaml / toml / json）: 「整形済みテキスト」または「ツリー」（`<details>` の入れ子）。
  JSON のみ既定でツリー。
- **他人のカーソル**: y-codemirror.next の既定表示（色付きキャレット + 名前ラベル）。
  `aria-hidden`。
- **読み取り専用**（viewer）: エディタの上に「閲覧のみです（<owner 名>が共有）」。
  CodeMirror は `readOnly`。ツールバーは 表示切替 / 書き出し / 印刷 のみ。

### 4.3 共有リンク入口（`/s/:token`）

- 有効: セッションが無ければゲストを発行 → `document_member` に upsert → `/d/:id` へ 302。
  画面は出ない。
- 失効・不明: 「このリンクは無効です。作成者に新しいリンクを依頼してください」+ ホームへ。
- 既に上位権限のメンバー: 権限を**下げない**（upsert は `max(role)`）。

### 4.4 共有ダイアログ（owner）

```
┌ 共有 ───────────────────────────────── [×] ┐
│ リンクを知っている人の権限                    │
│  (●) 編集できる  ( ) 閲覧のみ                │
│  有効期限 [90 日 ▾]                          │
│  [リンクを作成]                              │
│                                              │
│ 有効なリンク                                 │
│  https://noter…/s/shr_…  編集  〜2026-12-05  [コピー][失効] │
│                                              │
│ 参加者                                       │
│  山田（あなた）owner                         │
│  佐藤            editor    [閲覧のみにする][外す] │
└──────────────────────────────────────────────┘
```

- 「リンクを作成」で 1 本作る。同じ権限のリンクを何本でも作れる（用途別に失効できる）。
- 失効 / 外す は確認なし（Undo トーストを 20 秒表示、AAA 2.2.3）。
- 外した人の接続は即座に `4403` で切れる（`/kick`）。

### 4.5 ログイン（`/sign-in`）

- 「Google でログイン」1 ボタン + 「ゲストのまま続ける」リンク。
- ゲストからのログインは**昇格**（文書は引き継がれる）と明記。
- Google が未設定（`isGoogleConfigured` が false）の環境ではボタンを出さず理由を出す。

## 5. 状態の言葉（ステータスピル）

`ConnectionState` × `SaveState` を 1 文言にする。読み上げは変化時 1 回（同じ文言の連続は抑制）。

| 状態                                 | ピル表示                | 読み上げ                                                       | 色      |
| ------------------------------------ | ----------------------- | -------------------------------------------------------------- | ------- |
| connecting                           | 接続中…                 | 接続しています                                                 | muted   |
| connected + saved                    | 同期済み · 12:34        | （初回のみ）接続しました                                       | success |
| connected + dirty（5 秒以内）        | 同期中…                 | （読まない）                                                   | muted   |
| reconnecting(n)                      | 再接続中… (n 回目)      | 再接続しています。編集は続けられます                           | warning |
| offline                              | オフライン · 端末に保存 | オフラインです。編集はこの端末に保存され、復帰後に送信されます | warning |
| rejected(forbidden)                  | 権限がありません        | この文書の権限が変更されました。再読み込みしてください         | danger  |
| rejected(not_found)                  | 文書が見つかりません    | 文書が削除されたか、アクセスできません                         | danger  |
| rejected(limit)                      | 本日の同期上限          | 本日の同期上限に達しました。編集はこの端末に保存されます       | danger  |
| persist failed（サーバから通知なし） | —                       | —（v1 では検出しない。budget §4 参照）                         |         |

**「保存」という語は使わない。** ユーザーが押すものが無いので「同期」で統一する。
例外は「端末に保存」（オフライン時の所在を示す）。

## 6. フロー

### 6.1 初めて使う（ゲスト）

```
/ → [Markdown で始める] → server fn: ゲストセッション発行 + 文書作成 → /d/:id
   → エディタにフォーカス（1 行目）→ 入力 → 「同期済み」
```

3 クリック以内。ログイン画面を経由しない。

### 6.2 共有して一緒に編集

```
owner: [共有] → 権限「編集できる」→ [リンクを作成] → [コピー] → チャットに貼る
guest: リンクを開く → (ゲスト発行) → /d/:id → 名前を聞く小さな `<dialog>`（初回のみ、
       既定「ゲスト-<4 文字>」、スキップ可）→ 編集開始 → owner 側に「〇〇さんが参加しました」
```

### 6.3 オフライン → 復帰

```
connected → (回線断) → offline「端末に保存」→ 入力継続 → (復帰) → reconnecting → connected
→ Yjs が差分を送受信 → 他人の変更と自動マージ（通知しない）
```

### 6.4 デプロイ中

DO は再起動し全 WS が切れる → 全員 `reconnecting` → 数秒で `connected`。
文言は 6.3 と同じ。**モーダルを出さない。**

### 6.5 上限到達

`rejected(limit)` → ピルが赤 → 入力は続けられる → 「書き出し」を促すバナー
（閉じられる）。翌日 09:00 JST 以降に再読み込みで同期。

## 7. キーボードショートカット

CodeMirror 既定（Cmd/Ctrl+Z 等）に加えて:

| キー                   | 動作                                                                  |
| ---------------------- | --------------------------------------------------------------------- |
| `Cmd/Ctrl + Shift + F` | 整形                                                                  |
| `Cmd/Ctrl + \`         | 表示切替（エディタ→分割→プレビュー）                                  |
| `Cmd/Ctrl + Shift + P` | 問題パネル開閉                                                        |
| `Cmd/Ctrl + S`         | 何もしない（`preventDefault` + 「自動で同期されています」を読み上げ） |
| `Esc` → `Tab`          | エディタから抜ける                                                    |
| `?`（エディタ外）      | ショートカット一覧                                                    |

## 8. 文言ルール

- 丁寧語、体言止めは避ける。「〜できません」ではなく「〜するには〜してください」。
- 技術語は避ける: Durable Object / CRDT / WebSocket は出さない。「同期」「接続」で言う。
- エラーは 3 部構成: **何が起きたか / 影響 / 次にできること**。
- ボタンは動詞: 「作成」「コピー」「失効」「外す」。「OK」「はい」は使わない。

## 9. 計測（無料枠内・プライバシー）

計測しない。Cloudflare のダッシュボードのリクエスト数だけ見る。
外部アナリティクスも Cookie 同意バナーも入れない。
