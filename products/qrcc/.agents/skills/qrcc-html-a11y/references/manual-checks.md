# 手動アクセシビリティ確認手順

axe / oxlint / markuplint が見つけるのは問題の約 3 割。以下は**必ず人間または
エージェントが操作して**確認する。PR 説明にチェック結果を書く。

## 1. キーボードのみ（マウス・トラックパッドに触らない）

- [ ] Tab だけで全機能に到達できる（生成・保存・共有・削除・印刷・カメラ起動）
- [ ] フォーカス位置が常に見える（sticky ヘッダの下に隠れない）
- [ ] Tab 順が視覚順と一致する
- [ ] ダイアログを開いたら中にトラップされ、Esc で閉じ、フォーカスがトリガーに戻る
- [ ] キーボードトラップがない（`iframe`・カメラプレビュー周辺に注意）
- [ ] Enter / Space がボタンで両方効く

## 2. 拡大・リフロー

- [ ] ブラウザ 400% ズームで横スクロールが出ない（320×256 CSS px 相当）
- [ ] ブラウザのフォントサイズを 200% にしても崩れない（`rem` を使っているか）
- [ ] 幅 320px で全機能が使える

## 3. 読み上げ

macOS: VoiceOver（Cmd+F5）、Windows: NVDA。最低でも VoiceOver で確認する。

- [ ] ローターの見出し一覧だけでページ構造が理解できる
- [ ] ランドマーク一覧が `banner / navigation / main / complementary / contentinfo`
      になっている
- [ ] 生成したコードの**内容がテキストとして読み上げられる**（画像 alt だけに頼らない）
- [ ] フォームエラーが発生時に読み上げられ、該当入力にフォーカスが移る
- [ ] カメラ読み取りの状態（開始・成功・失敗・権限拒否）が読み上げられる
- [ ] リンク一覧を単体で読んで行き先が分かる（AAA 2.4.9）

## 4. 色・コントラスト

- [ ] ライト/ダーク両方でテキスト 7:1、UI 境界 3:1（AAA 1.4.6）
- [ ] Windows ハイコントラスト（`forced-colors: active`）で情報が消えない
- [ ] グレースケール表示にして、色だけで区別している箇所がないか確認
- [ ] フォーカスリングが背景と 3:1 以上、太さ 2px 以上（AAA 2.4.13）

## 5. モーション・時間

- [ ] OS の「視差を減らす」を ON にして動きが止まる
- [ ] 自動で消える通知がない、または 20 秒以上表示される
- [ ] セッション期限切れでデータが失われない（AAA 2.2.6）

## 6. 対象サイズ

- [ ] すべてのクリック対象が 44×44 CSS px 以上（AAA 2.5.5）
- [ ] 一覧の行内アクション（編集・削除）が密集していない

## 7. 印刷

- [ ] 印刷プレビューでラベルが用紙からはみ出さない
- [ ] 印刷時にリンク先 URL が出る
- [ ] ダークモードで印刷しても白背景・黒文字になる
