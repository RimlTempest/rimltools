# アクセシビリティ方針と WCAG 2.2 AAA 達成状況

目標は **WCAG 2.2 レベル AAA**。到達できない項目は理由と代替手段をここに記録する。
実装時の規約は `.claude/skills/qrcc-html-a11y/`。

## 1. 方針

1. 意味の合う HTML 要素を最優先。ARIA は補強にのみ使う。
2. 状態表現とレイアウトは CSS で完結させ、JS が落ちても主要機能が動く。
3. 生成したコードは**画像だけで提供しない**。必ず内容をテキストでも出す。
4. 自動チェック（oxlint jsx-a11y / markuplint / axe-core）は前提条件であって
   合格条件ではない。手動確認（`references/manual-checks.md`）を必ず行う。

### 読み取り画面（`/scan`）で新たに関係する基準

カメラという「見えないと使えない」入力を扱うため、この画面だけの取り決めがある。

| 基準                       | この画面での扱い                                                                                     |
| -------------------------- | ---------------------------------------------------------------------------------------------------- |
| 1.1.1 非テキストコンテンツ | `<video>` は `aria-hidden="true"`。映像から得られる情報は無く、読めた内容は必ずテキストで出す        |
| 2.1.1 / 2.1.3 キーボード   | カメラが無い・許可されない環境でも、画像ファイルからの読み取りだけで全機能が完結する                 |
| 4.1.3 ステータスメッセージ | 開始・成功・失敗・権限拒否をすべて 1 つの `role="status"` に集約する。状態の表示場所を分散させない   |
| 2.2.3 タイミング非依存     | 読み取りに制限時間を設けない。カメラは利用者が止めるまで動き続ける                                   |
| 2.4.9 リンクの目的         | 読み取った URL はその URL 自体をリンクテキストにする。`http(s)` 以外はリンクにせずテキストのまま出す |

**同じ値の連続検出は読み上げを更新しない。** カメラは 1 つのコードを毎秒何度も
検出するので、素直に読み上げると支援技術が鳴り続けて他の操作ができなくなる。
また読み上げ文は 60 文字で切り詰める（履歴には全文を残す）。

### 到達困難な項目と代替

| 基準                                 | 状況                                                                          | 代替                                                                                                  |
| ------------------------------------ | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1.2.6 手話 / 1.2.8 メディア代替      | 動画コンテンツを持たないため **非該当**                                       | —                                                                                                     |
| 3.1.4 略語                           | 「QR」「EC レベル」等は初出で `<abbr title>` + 用語集で対応                   | 用語集ページ                                                                                          |
| 3.1.6 発音                           | 日本語の同音異義が問題になる箇所は現状なし。発生したら `ruby` を使う          | —                                                                                                     |
| 1.4.6 コントラスト（ユーザー指定色） | **ユーザーが QR の色を自由に指定できる**ため、生成物自体は 7:1 を保証できない | 保存前にコントラスト比を計算し、閾値未満なら警告 + 修正候補を提示。UI 自体（周囲の文字）は 7:1 を維持 |

## 3. 検証

```
bun run lint        # oxlint jsx-a11y
bun run lint:html   # markuplint (a11y preset)
bun run a11y        # Playwright + axe-core (wcag2a, wcag2aa, wcag2aaa, wcag22aa)
```

CI は上記 3 つすべてを必須にする。加えて PR には
`.claude/skills/qrcc-html-a11y/references/manual-checks.md` の
チェック結果を貼る。

## 4. 画面ごとの状況

| 画面             | 特に効いている配慮                                                                                                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 共通（ヘッダー） | ランドマーク、スキップリンク、`aria-current="page"`（AAA 2.4.8）。**ヘッダーのサインイン状態は live region にしない** — 常駐する live region は遷移のたびに読み上げられ、ページ側の通知と競合する |
| 生成             | 生成した内容をテキストでも併記（1.1.1）。ライブ更新では**問題だけ**を読み上げる。低コントラストは拒否せず警告                                                                                     |
| 読み取り         | `<video>` は `aria-hidden`、状態は単一の live region に集約。同値の連続検出は読み上げを抑制。カメラが使えなくても画像読み取りで完結                                                               |
| 印刷             | 台紙は物理寸法なのでプレビュー領域だけが横スクロールし、その領域はキーボードで送れる（2.1.1 / axe scrollable-region-focusable）                                                                   |
| サインイン       | Google とゲストの 2 択のみ。パスワードの記憶もパズルも課さない（AAA 3.3.9）                                                                                                                       |

## 5. 更新ルール

- 新しい画面を追加したら、この表に「その画面で新たに関係する基準」を追記する。
- AAA を諦める判断は必ずこの文書に理由付きで記録する（口頭で決めない）。
