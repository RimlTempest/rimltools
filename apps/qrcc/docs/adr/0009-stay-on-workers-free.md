# ADR-0009: Workers Free プランに留まり、R2 と KV を使わない

- 状態: Accepted
- 日付: 2026-09-02
- 関連: [ADR-0001](0001-stack-selection.md) / [ADR-0003](0003-rust-core-dual-target.md) / [ADR-0005](0005-pdf-and-label-printing.md)

## 文脈

本プロジェクトの絶対条件は「**無料で運用できること**」（[ADR-0001](0001-stack-selection.md)）。
デプロイ準備で Cloudflare のリソースを作る段になり、
「**こちらが許可しない限り絶対に課金されない**」ことを構造的に保証できるか、を確かめた。

調べた結果:

|                                          | 超過したときの挙動                                                          |
| ---------------------------------------- | --------------------------------------------------------------------------- |
| Workers Free（Workers / D1 / KV を含む） | **課金されない。** 上限に達するとリクエストがエラー（429 等）になって止まる |
| R2                                       | **従量課金される。** しかも Workers Paid とは独立に課金される               |

そして **R2 には利用上限（ハードキャップ）を設定する機能がない。**
できるのはアラート通知だけで、「ここで止める」ができない。長年の要望として
上がっているが 2026 年時点でも未実装。

つまり **R2 を有効化した時点で「絶対に課金されない」は成立しなくなる。**

## 決定

- **Workers Free プランに留まる。** Workers Paid を契約しない
- **R2 を使わない。** 有効化もしない（有効化には支払い方法の登録が要る）
- **KV も使わない。** 課金リスクは無いが、使わない宣言を残さない
- 使うのは **D1 と service binding だけ**にする

## 理由

### R2 は、もう要らなくなっていた

当初 R2 に想定していた用途は、設計が進む過程ですべて消えた。

| 当初の用途                    | 現状                                                                                                  |
| ----------------------------- | ----------------------------------------------------------------------------------------------------- |
| 生成物（PNG/PDF）のキャッシュ | 不要。生成はブラウザ内の wasm で完結し Worker を通らない（[ADR-0003](0003-rust-core-dual-target.md)） |
| PDF 生成物の保管              | 不要。PDF はスコープ外にし、ブラウザ印刷を主経路にした（[ADR-0005](0005-pdf-and-label-printing.md)）  |
| アップロード画像の一時保管    | 不要。読み取りは端末内で完結し、画像はサーバに送らない                                                |

**課金リスクを負ってまで得るものが無い。**

### KV も、もう要らなくなっていた

| 当初の用途                 | なぜ使わないか                                                                                                                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| レート制限のカウンタ       | KV の無料枠は**書き込み 1,000/日**しかなく、プロジェクト全体で最もきつい制約。リクエストごとに書く用途は真っ先に枯れる。D1 の 1 行 upsert か Cache API を使う                                       |
| 共有リンクの解決キャッシュ | 解決は索引の効いた D1 の 1 行読み取り（`share_link_code_idx`）で済む。D1 の読み取り枠は 500 万行/日と潤沢。キャッシュしても得るものが小さい一方、共有リンク作成のたびに**一番きつい制約を消費する** |

## 帰結

- **支払い方法を登録しない限り、構造的に課金されない。** 上限に達したらアプリが
  エラーを返すだけで、請求は発生しない
- 両 `wrangler.jsonc` から `r2_buckets` と `kv_namespaces` の宣言を消した。
  作成済みだった KV 名前空間も削除した
- **キャッシュが必要になったら、まず Cache API を検討する。**
  Workers 内蔵で独自の無料枠を持たないため、この決定を壊さない
- R2 を使いたくなったときは、この ADR を読み直したうえで
  「ハードキャップが実装されたか」を確認し、新しい ADR で決め直すこと。
  **黙って有効化しない**
- `docs/free-tier-budget.md` の予算表と縮退表も、この決定に合わせて更新した
